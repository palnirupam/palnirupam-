## Flagship work

**Private projects** · Selected summaries of work I maintain in private repositories.

### Dhruva V1 · Experimental language model

**~99.5M parameters · PyTorch · 64K BPE · English / Bengali / Hindi**

A decoder-only Transformer built from scratch with GQA and SwiGLU, plus a custom multilingual tokenizer. Its compound AI architecture combines routing, deterministic tools, BM25 retrieval and verification. The current release is a **Stage 1A experimental base-model checkpoint**.

### Maya AI · Windows-first assistant

An AI assistant for desktop actions, files and browser workflows, with a **FastAPI/WebSocket backend and React/Vite interface**. V1 is the current user-facing runtime; Brain V2 is an experimental, default-off foundation.

### WS Tester Pro · WebSocket security tooling

A WebSocket assessment framework with a **CLI and browser dashboard**, traffic interception and replay, response comparison, configurable validation and multi-format reports.
